# Suvaria Homebrew Rules

_Converted from the original Homebrewery source into portable Markdown. [View the published Homebrewery document](https://homebrewery.naturalcrit.com/share/rJ7ZNiEKwV)._

Welcome, traveler from an antique land. The old Homebrewery tome has been separated into smaller volumes so finding one rule no longer requires defeating six hundred lines of Markdown first.

<div class="portal-note"><strong>Table ruling wins.</strong> These pages preserve imported campaign rules and older rewards as written. If a current character handout or a ruling at the table disagrees with an older entry, use the current handout or ruling.</div>
